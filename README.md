## 📖 The Story Behind Shqiponja

**SHQIPONJA Energy** is an adrenaline-fueled lifestyle brand conceived for dreamers, athletes, creators, and night-owls. Taking inspiration from the soaring strength of the eagle (*Shqiponja*), the beverage combines 100% natural caffeine, zero refined sugars, neuro-adaptogens, and organic electrolytes in sleek, textured matte-finish cans.

The digital web experience was engineered to match the drink's raw kinetic energy: hyper-smooth scroll inertia, vibrant electric crimson palettes, interactive cursor spark effects, and 3D flavor showcases.

---

## ✨ Key Functions & Experience

### 1. Lenis Butter-Smooth Momentum Scroll
- **Fluid Kinetic Inertia**: Powered by `@studio-freight/lenis`, delivering seamless trackpad and mousewheel momentum across all viewports.
- **Parallax Layering**: Floating can assets, dynamic typography, and background gradients move at differentiated speeds.

### 2. Interactive Cursor Particle Sparks
- **ClickSpark Engine**: Every click generates real-time crimson and neon particle sparkles that scatter across the DOM with realistic physics.

### 3. Kinetic Flavor Showcase & Carousel
- **Dynamic Can Showcase**: Interactive flavor switching featuring:
  - *Crimson Fury (Wild Berry & Blood Orange)*
  - *Volt Lime (Zesty Key Lime & Taurine)*
  - *Arctic Frost (Glacial Mint & Electrolytes)*
- **Nutritional Deep-Dive**: Instant toggles revealing caffeine dosage, zero-sugar certifications, and vitamin B-complex blends.

### 4. Bento Grid Innovation Section
- High-contrast visual grid breaking down cold-brew caffeine extraction, recyclable aluminum packaging, and athletic performance stats.

### 5. Athlete Activations & Social Ingestion
- Interactive voting for community activations and localized extreme sports tour sponsorship announcements.

## 🚀 Quick Start & Local Development

```bash
# Clone the repository
git clone https://github.com/orivojka-eng/shqiponja.git

# Navigate to directory
cd shqiponja

# Install dependencies
npm install --legacy-peer-deps

# Start development server
npm run dev
```
